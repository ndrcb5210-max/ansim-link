CLAUDE.md를 먼저 읽고 **4단계(위치 공유와 안심 메시지)** 를 진행해 줘. 지금 브랜치는 `feature/04-share-message`다. 앞 단계 devlog를 먼저 확인해.

배경(이미 확인한 사실)
- 공식 문서: 앱이 백그라운드에 있을 때는 ACCESS_BACKGROUND_LOCATION 없이 위치 포그라운드 서비스를 만들 수 없다. 사용자가 알림을 눌러 시작하면 예외로 허용된다.
- Google Play: 포그라운드 서비스 위치 사용은 사용자가 시작한 동작의 연장이어야 하며, 자동 시작은 백그라운드 위치 심사 대상이다.
- FCM 발송은 서버 자격 증명이 필요해 앱에서 직접 보내면 안 된다. Cloud Functions는 Blaze 요금제가 필요하다.
- Firestore 무료 요금제는 하루 쓰기 2만 건이다.

할 일
1. **위치 공유 포그라운드 서비스**(type=location)
   - 시작 경로: (a) 3단계 중요 알림의 ‘공유 시작’ 버튼, (b) 앱 화면의 ‘지금 공유’ 버튼, (c) ‘자동 시작’ 모드(설정에서 켠 경우만).
   - 공유 시간: 기본 60분(무료 최대 60분, 프리미엄 최대 180분 상수). 끝나면 자동 종료.
   - 상시 알림: “가족 그룹 ○명에게 내 위치를 공유 중 · 18:05 시작 · 19:05 종료 예정” + [지금 중지] 버튼.
   - 위치 업데이트: Fused Location, 60초 간격, 50m 이상 움직였을 때만 Firestore에 쓴다.
   - 시작할 때마다 **제공 기록**(누구에게·언제·목적)을 Firestore와 로컬에 남기고, 앱 안 ‘내 위치 제공 기록’ 화면에서 보이게 한다(위치정보법 제19조③ 즉시 통보·기록).
   - 동의를 철회했거나 일시중지 중이면 시작하지 않는다.
2. **자동 시작 모드**
   - 설정에서 켤 때: 명시적 공개 화면(“앱이 닫혀 있거나 사용하지 않을 때도 재난문자를 받으면 위치를 수집해 그룹에 공유합니다” + 쓰는 기능 목록) → 위치 권한 → 백그라운드 위치 권한(설정 화면 이동 안내). 순서를 지킨다.
   - 리스너에서 자동 시작에 실패하면(ForegroundServiceStartNotAllowedException, SecurityException) ‘눌러서 시작’ 알림으로 대신한다.
3. **안심 메시지**
   - 설정에서 공통 메시지 1개(프리미엄은 재난 유형별) 편집. 기본 문구: “재난문자 받았어. 나는 괜찮아. 앱에서 내 위치를 확인해 줘.”
   - 발동 시 규칙에 맞으면 WorkManager 작업으로 Firestore `groups/{gid}/alerts/{id}`(보낸 사람, 종류, 유형, 메시지, 시각)를 만든다. 앱은 FCM을 직접 보내지 않는다.
4. **서버(functions/)**: Cloud Functions(TypeScript, 2세대). `onAlertCreated`(alerts 문서 생성 시 그룹 구성원 토큰으로 FCM HTTP v1 발송, 보낸 사람 제외), `onShareStarted`(공유 시작 알림), 세션 만료 정리 스케줄 함수(마지막 위치 24시간 후 삭제). 단위 테스트(firebase-functions-test 또는 순수 함수 분리). 배포는 하지 않는다. `functions/README.md`에 Blaze 요금제와 배포 명령을 적는다.
5. **FCM 수신**(앱): 토큰 등록(members 문서), 메시지 알림 표시(“엄마: 재난문자 받았어…” + [위치 보기]), 공유 시작 알림. Android 13+ 알림 권한 요청 흐름.
6. **가족 위치 보기 화면**: 지도 SDK 없이 구성원별 마지막 위치 시각·정확도·내 위치와의 거리, [지도 앱으로 열기](geo: 인텐트) 버튼. 공유 중인 사람만 보인다.
7. 보안 규칙 갱신: 위치 문서는 해당 그룹 구성원만 읽기, 본인만 쓰기, 동의·일시중지 상태 확인.
8. 테스트: 공유 시간 계산·종료, 50m 판정, 동의/일시중지 시 시작 거부, 메시지 선택 로직 단위 테스트. Roborazzi `docs/screenshots/04/`. `./gradlew lint testDebugUnitTest assembleDebug` 통과, `docs/devlog/04-share-message.md`, 의미 단위 커밋(푸시는 하지 마라).

하지 말 것: SMS 권한 추가, 동의 없는 위치 수집, 클라이언트에 서버 키 넣기, 지도 API 키 커밋.
