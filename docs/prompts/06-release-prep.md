CLAUDE.md를 먼저 읽고 **6단계(출시 준비)** 를 진행해 줘. 지금 브랜치는 `feature/06-release-prep`이다. 앞 단계 devlog를 모두 확인해.

할 일
1. **릴리스 빌드**: 서명 설정을 환경 변수(`ANSIM_KEYSTORE_PATH`, `ANSIM_KEYSTORE_PASSWORD`, `ANSIM_KEY_ALIAS`, `ANSIM_KEY_PASSWORD`)로 받는다. 값이 없으면 릴리스 서명을 건너뛰고 경고만 낸다. R8 축소·난독화 켜고 필요한 keep 규칙을 둔다. `bundleRelease`로 AAB가 만들어지는지 확인한다(로컬에서 임시 키로 시험하되 키는 저장소 밖 `%TEMP%`에 만들고 커밋하지 않는다).
2. **GitHub Actions 릴리스 워크플로**(`release.yml`): 태그 `v*` 푸시 시 시크릿으로 키스토어를 복원해 AAB를 만들고 아티팩트로 올린다. Play 업로드 단계는 주석으로만 두고 필요한 시크릿과 설정을 문서화한다(실제 업로드는 하지 않는다).
3. **문서**(GitHub Pages로 공개할 수 있게 `docs/site/`):
   - 개인정보 처리방침(개인정보 보호법 제30조 항목 + 위치정보법 제21조의2 항목: 개인위치정보 처리 목적·보유기간, 확인자료 보유 근거·기간, 파기, 제3자 제공)
   - 위치정보 이용약관(2단계 초안 정리)
   - 계정 삭제 요청 안내(2단계 초안 정리)
   - 이 문서들이 앱 안 링크와 같은 내용인지 확인한다.
4. **Play Console 제출 자료 초안** `docs/play/`:
   - 스토어 등록정보(짧은 설명 80자, 자세한 설명): 위치 공유 기능을 분명히 적고 ‘감시’, ‘몰래’ 같은 표현을 쓰지 않는다. “재난문자 감지를 보장하지 않음”을 적는다.
   - 데이터 보안(Data safety) 항목표: 수집·공유하는 데이터(정밀 위치, 이메일, 이름, 기기 ID/푸시 토큰, 구매 내역), 목적, 선택/필수, 암호화, 삭제 요청 가능 여부.
   - 권한 선언 문구: 백그라운드 위치(자동 시작 모드) 선언서 답변 초안, 포그라운드 서비스(location) 설명, 시연 영상 촬영 대본(30초 이내).
   - 앱 콘텐츠: 대상 연령(만 14세 이상, 아동 대상 아님), 콘텐츠 등급 설문 예상 답변, 광고 없음.
   - 비공개 테스트 운영 계획: 테스터 12명 이상 14일 연속, 모집·안내 문구, 피드백 수집 방법, 프로덕션 신청서 3개 항목 답변 초안.
5. **출시 체크리스트** `docs/RELEASE_CHECKLIST.md`: 위치기반서비스사업 신고(위치정보법 제9조·제9조의2, 확인 필요 사항 포함), 개인정보 처리방침 공개 URL, 계정 삭제 웹 URL, Firebase Blaze 전환과 함수 배포, 실제 google-services.json, 서명 키 보관, 대상 API 36, Billing Library 버전, 실기기 재난문자 패키지 확인 결과 기록란.
6. `./gradlew lint testDebugUnitTest assembleDebug` 통과(릴리스는 키가 있을 때만), `docs/devlog/06-release-prep.md`, 의미 단위 커밋(푸시는 하지 마라).

하지 말 것: 실제 키·비밀번호를 저장소에 넣지 마라. 하지 않은 출시 절차를 ‘완료’로 적지 마라.
