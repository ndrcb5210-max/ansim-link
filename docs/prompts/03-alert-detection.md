CLAUDE.md를 먼저 읽고 **3단계(재난문자 감지와 발동 규칙)** 를 진행해 줘. 지금 브랜치는 `feature/03-alert-detection`이다. 앞 단계 devlog(01, 02)를 먼저 확인해.

배경(이미 확인한 사실)
- 일반 앱은 셀 방송(재난문자)을 직접 받을 수 없다. 기본 재난문자 앱이 띄운 **알림**을 NotificationListenerService로 읽는다.
- 대상 패키지 허용 목록: `com.google.android.cellbroadcastreceiver`, `com.android.cellbroadcastreceiver`, `com.android.cellbroadcastreceiver.module`. 삼성 기기의 실제 패키지는 아직 모른다.
- 한국 알림 제목(AOSP 리소스): “위급 재난문자”, “긴급 재난문자”, “안전 안내문자”, “실종 경보문자”. 일반 ko 리소스는 “긴급 재난 문자”, “안전 안내 문자”처럼 띄어쓰기가 다르다. 영어: Extreme Emergency Alert, Emergency Alert, Public Safety Alert, Amber Alert. 미읽음이 여럿이면 “새 경보”, “읽지 않은 경보 N개”처럼 본문 없는 묶음 알림이 온다.
- Android 15부터 OTP로 판단된 알림은 내용이 가려질 수 있다.

할 일
1. 순수 Kotlin 모듈(또는 패키지)로 **분류기**를 만든다.
   - 입력: 패키지명, 제목, 본문, 채널 ID. 출력: 문자 종류(위급/긴급/안전안내/실종경보/미상), 재난 유형(CLAUDE.md의 35종 어휘를 설정 화면용 12개 그룹으로 묶은 값), 신뢰도(제목 일치 여부 등).
   - 제목은 공백을 지우고 한국어·영어 모두 비교한다. 본문 키워드로 유형을 정하고 여러 개가 맞으면 우선순위(지진해일 > 지진 > 민방공 > 산사태 > 홍수 > 호우 > 태풍 > 산불 > 대설 > 한파 > 폭염 > 기타)로 정한다.
   - 실제 재난문자 문구 예시(공개 보도·행정안전부 공개 자료에 실린 문장 형태)를 참고해 **단위 테스트 30개 이상**을 만든다. 테스트 문장의 출처 성격을 테스트 파일 주석에 적는다(지어낸 예시면 ‘예시’라고 적는다).
2. **발동 규칙 엔진**: 사용자가 정한 (문자 종류 × 재난 유형) 표에 따라 발동 여부를 판단한다. 기본값: 위급·긴급은 모든 유형 켬, 안전안내는 끔. 같은 본문은 10분 안에 한 번만(해시) 발동. 규칙 엔진도 단위 테스트한다.
3. **NotificationListenerService**: 허용 목록 패키지의 알림만 처리하고 나머지는 즉시 버린다(저장하지 않음). 분류 → 규칙 → 발동 이벤트를 로컬 DB(Room)에 기록한다(시각, 종류, 유형, 본문 앞 60자, 발동 여부와 이유).
   - 발동되면 지금 단계에서는 **‘가족에게 위치를 공유할까요?’ 중요 알림**만 띄운다(버튼: 공유 시작 / 안심 메시지만 보내기 / 닫기). 버튼 동작은 4단계에서 연결하므로 지금은 로그만 남긴다.
4. 화면
   - 감지 설정 안내 화면: 왜 알림 접근이 필요한지, 무엇을 읽고 무엇은 저장하지 않는지 먼저 설명(명시적 공개) → 설정 열기(`ACTION_NOTIFICATION_LISTENER_DETAIL_SETTINGS`, 없으면 일반 설정). 사이드로드 설치 시 ‘앱 정보 > 더보기 > 제한된 설정 허용’ 안내. “모든 재난문자를 감지한다고 보장할 수 없습니다” 문구.
   - 발동 규칙 화면: 문자 종류 3행 × 재난 유형 12열 대신, 문자 종류별 스위치 + 유형 칩 선택 UI로 쉽게.
   - 발동 기록 화면: 최근 50건.
   - 디버그 빌드 전용 ‘테스트 재난문자 보내기’: 앱이 직접 같은 제목·본문 형식의 알림을 띄워 리스너 흐름을 시험한다(디버그에서는 자기 패키지를 허용 목록에 추가). 디버그 전용 ‘받은 알림 패키지 기록’ 화면으로 실기기 패키지를 확인할 수 있게 한다.
5. Roborazzi 스크린샷 `docs/screenshots/03/`, `./gradlew lint testDebugUnitTest assembleDebug` 통과, `docs/devlog/03-alert-detection.md`, 의미 단위 커밋(푸시는 하지 마라).
