# docs/play — Play Console 제출 자료 초안

Google Play Console 에 넣을 글을 미리 적어 둔 **초안**이다. 6단계(출시 준비)에서 만들었다.

> **아무것도 제출하지 않았다.** 이 저장소에는 Play Console 계정이 없다. 아래 문서는 전부
> '넣을 글'이고, 실제로 넣어 본 결과는 없다. Console 화면의 질문 문구와 선택 항목은
> 바뀌므로, 옮겨 적을 때 화면과 다르면 **화면을 따른다**. 확인하지 못한 것은 각 문서에
> `확인 필요` 로 적어 두었다.

| 문서 | Console 위치 | 내용 |
| --- | --- | --- |
| [store-listing.md](store-listing.md) | 성장 > 스토어 설정 > 기본 스토어 등록정보 | 앱 이름, 짧은 설명(80자), 자세한 설명, 그래픽 자산 목록 |
| [data-safety.md](data-safety.md) | 정책 > 앱 콘텐츠 > 데이터 보안 | 수집·공유하는 데이터 항목표, 목적, 필수/선택, 암호화, 삭제 요청 |
| [permissions-declaration.md](permissions-declaration.md) | 정책 > 앱 콘텐츠 > 민감한 권한, 포그라운드 서비스 | 백그라운드 위치 선언서, 포그라운드 서비스(location) 설명, 시연 영상 대본 |
| [app-content.md](app-content.md) | 정책 > 앱 콘텐츠 | 대상 연령, 콘텐츠 등급 설문, 광고, 그 밖의 선언 |
| [closed-testing-plan.md](closed-testing-plan.md) | 테스트 및 출시 > 테스트 > 비공개 테스트 | 테스터 12명·14일 운영 계획, 모집·안내 문구, 피드백 수집, 프로덕션 신청서 답변 |

## 같은 내용을 여러 군데 적는 자리

Play Console 의 답변은 **앱 화면·약관과 어긋나면 안 된다.** 어긋나면 심사에서 걸리는 것을
넘어, '앱이 설명한 것과 다르게 동작한다'는 뜻이 된다. 아래가 같은 내용을 말해야 하는 자리다.

| 내용 | 앱 | 공개 문서 | Play Console |
| --- | --- | --- | --- |
| 위치를 언제 수집하는지 | 위치 권한 설명 화면, 자동 시작 명시적 공개 | [위치기반서비스 이용약관](../legal/location-terms.md) 제4조 | 데이터 보안, 백그라운드 위치 선언서 |
| 누구에게 제공하는지 | 참여 동의 화면, 그룹 화면 | 처리방침 4항 | 데이터 보안 '공유' |
| 확인자료 보유 기간(180일) | 제공 기록 화면, 계정 삭제 화면 | 약관 제6조, 처리방침 3항 | — |
| 계정·데이터 삭제 방법 | 설정 > 계정 > 계정 삭제 | [계정 삭제 안내](../account-deletion.md) | 데이터 보안 '삭제 요청 URL' |
| 감지를 보장하지 않는다 | 감지 설정 안내 화면 | 약관 제11조 | 자세한 설명 |
